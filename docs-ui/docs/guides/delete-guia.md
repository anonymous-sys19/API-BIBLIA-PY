# Eliminar Guía de Estudio

Elimina permanentemente una guía y sus etiquetas

<div class="endpoint-badge">
  <span class="method delete">DELETE</span>
  <code class="endpoint-path">/guide/{id}</code>
</div>

```bash
curl -X DELETE "https://api.tu-dominio.com/guide/1"
```

## Respuesta

```json
{
  "mensaje": "Guía eliminada"
}
```
