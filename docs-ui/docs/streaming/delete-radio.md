# Eliminar Radio

Elimina una estación de radio

<div class="endpoint-badge">
  <span class="method delete">DELETE</span>
  <code class="endpoint-path">/stream/{radio_id}</code>
</div>

## Respuesta

```json
{
  "mensaje": "Radio eliminada"
}
```

## Ejemplo

```bash
curl -X DELETE https://api.tu-dominio.com/stream/5
```
